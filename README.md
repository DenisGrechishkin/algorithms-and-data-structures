## Содержание репозитория

### Лабораторная работа №1: Сортировка и поиск
- **Шейкерная сортировка** — улучшение пузырьковой сортировки за счёт двустороннего прохода.
- **Поиск Фибоначчи** — эффективный поиск в отсортированном массиве без деления нацело.
- *Пример:* сортировка `[71, 22, 19, ...]` → `[11, 19, 22, ...]`, поиск ключа `34` → "Ключ найден".

### Лабораторная работа №2: Минимальный остов графа
- **Алгоритм Краскала** — построение минимального остова взвешенного неориентированного графа.
- *Пример:* граф с 6 вершинами и 10 рёбрами → остов из 5 рёбер с общей стоимостью 66.
- Проверка корректности: количество рёбер = n_ver - 1 → алгоритм работает верно.

### Лабораторная работа №3: Кратчайшие пути в графе
- **Алгоритм Дейкстры** — поиск кратчайших путей от заданной вершины до всех остальных.
- *Пример:* от вершины 5 (индекс 4) до всех других: расстояния [8, 11, 7, 6, 0, 4].
- Используется матрица смежности, обработка весов > 0, отслеживание посещённых вершин.

### Лабораторная работа №4: Задача коммивояжёра
- **Метод ветвей и границ** — точное решение TSP для малых графов (N=4).
- *Пример:* матрица смежности 4x4 → минимальная стоимость 95, путь: `0 → 2 → 1 → 3 → 0`.
- Реализация включает оценку нижней границы, рекурсивный перебор с отсечением.
